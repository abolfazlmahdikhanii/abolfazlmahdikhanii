## 🚀 Featured Projects

### Twitifa — Twitter/X-Style Social Platform
Full-stack app with 10+ API routes, real-time notifications, cursor-based infinite scroll
(TanStack Query + React Virtuoso), rich-text composer (Tiptap), JWT + Google OAuth with a
multi-step password reset, and a Recharts analytics dashboard.
`Next.js 16` `React 19` `MongoDB` `HeroUI` `Tiptap` `ImageKit`
🔗 [Source](https://github.com/abolfazlmahdikhanii/twitifa) · [Live Demo](https://twitifa.vercel.app)

### Maliyar — Personal Finance Manager (TypeScript)
Persian RTL app with Jalali-calendar filtering for accounts, transactions, budgets and
loans; Convex back-end with linked records and a Gemini-powered AI assistant that creates
entries from free text.
`TypeScript` `React` `Convex` `Vercel AI SDK` `HeroUI`
🔗 [Source](https://github.com/abolfazlmahdikhanii/maliyar) · [Live Demo](https://maliyar.vercel.app)

### Rentify — Real Estate Platform
Rental platform with 8+ API routes: listings CRUD, favorites, comparison and visit
scheduling; JWT auth in HTTP-only cookies with role-based access, filtered search and
Nodemailer notifications.
`Next.js` `MongoDB` `Mongoose` `SWR` `JWT` `Nodemailer`
🔗 [Source](https://github.com/abolfazlmahdikhanii/rentify) · [Live Demo](https://rentify-kbax.vercel.app)

### ChatGram — Real-Time Chat App
Real-time messaging on Supabase subscriptions with Row Level Security and an accept/reject
chat-request flow; file and audio sharing with live upload progress and in-app voice
playback.
`React` `Vite` `Supabase` `Tailwind CSS` `WaveSurfer.js`
🔗 [Source](https://github.com/abolfazlmahdikhanii/chatgram) · [Live Demo](https://chatgram-seven.vercel.app)

### Digi-Blog — Full-Stack Blog
SSR/SSG blog with three roles (Admin, Author, Reader), post management, comments, likes,
bookmarks, topic filters and dark/light mode.
`Next.js` `MongoDB` `Tailwind CSS` `shadcn/ui`
🔗 [Source](https://github.com/abolfazlmahdikhanii/digi-blog) · [Live Demo](https://digi-blog-one.vercel.app)
